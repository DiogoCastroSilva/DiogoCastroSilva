# hey, i'm Diogo 👋

I'm a software engineer who likes building products and figuring out how to make them better. I mostly work with React and TypeScript, but I also work across the stack when needed.

I enjoy taking a feature from an idea to something people can actually use, figuring out the tricky parts along the way, and finding a good balance between getting things done and keeping the code easy to work with.

### what i usually work with

- **Frontend:** React, TypeScript, JavaScript, component architecture, accessibility and performance
- **Backend:** Node.js, NestJS, GraphQL and PostgreSQL
- **Product development:** Building features end to end, working through complex workflows, and improving things based on feedback
- **AI:** Building AI-powered features and using tools like Cursor and Claude Code to speed up development. I like using AI to generate code, then checking whether it actually works through tests, end-to-end flows and code review.
