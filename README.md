# Hey, I'm Diogo 👋

I'm a software engineer who enjoys building products and figuring out how to make them better. My main focus is **React, TypeScript, and frontend engineering**, but I'm comfortable working across the stack when a feature needs it.

I like taking ideas from rough requirements to working features, solving the tricky parts along the way, and finding the right balance between shipping something useful and keeping the code maintainable.

### What I work with

- **Frontend:** React, TypeScript, JavaScript, component architecture, accessibility, and performance
- **Backend:** Node.js, NestJS, GraphQL, and PostgreSQL
- **Product engineering:** Building features end to end, working through complex workflows, and improving usability
- **AI-assisted development:** Using tools like Cursor and Claude Code to move faster, while validating the results through tests, real workflows, and code review

### Things I've been building

**[Frontend Product Engineering Lab](https://github.com/DiogoCastroSilva/frontend-product-engineering-lab)**

An ongoing project where I'm exploring frontend engineering beyond individual screens. I'm building a reusable React design system with design tokens, Storybook, accessibility, and testing, using Fieldnote as a product to put those ideas into practice.

**[Frontend Tooling](https://github.com/DiogoCastroSilva/frontend-tooling)**

I created and published reusable npm packages for ESLint, TypeScript, and Prettier configurations. The goal is to share a consistent development setup across projects without starting from scratch every time.

The tooling repository is also [included in the XERJ Corpus Hub](https://hub.xerj.org/contributors/DiogoCastroSilva) as a reference for AI coding agents.

**[Academic Portfolio](https://github.com/DiogoCastroSilva/academic-portfolio)**

A website I'm building for my wife, using Next.js and Nx. It uses Markdown for content such as projects and publications, with a focus on making updates straightforward without constantly changing application code.
